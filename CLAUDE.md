# Claude Configuration

## Skills

Read and follow [`SKILL.md`](./SKILL.md) before creating any new topic content in this repository. It defines the required structure, formatting, code example conventions, and quality checklist for all articles.

## Repository Context

This is a frontend system design knowledge base. Content is organized into chapter directories, each containing Markdown articles on specific topics. There is no application code, build system, or dependencies -- only Markdown documentation.

## Guidelines

- Follow the content structure defined in `SKILL.md` for all new articles.
- Distribute code examples throughout sections rather than grouping them at the end.
- Always include a "Common Beginner Doubts or Questions" section as the final section.
- Show code patterns across React, Vue, and Angular when the topic is framework-agnostic.
- Update `README.md` after adding any new article.
- Use kebab-case with capitalized words for file names: `Topic-Name.md`.
