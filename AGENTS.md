# Agents Configuration

## Skills

### Content Generator

- **File:** [`SKILL.md`](./SKILL.md)
- **Purpose:** Generates new frontend system design topic articles that match the format, depth, and structure of existing content in this repository.
- **When to use:** Any time a new topic article needs to be created or an existing one needs to be expanded.

## Instructions

1. Before creating any new content, read `SKILL.md` and follow its structure exactly.
2. After creating a new article, update `README.md` with a link to the new topic.
3. Place articles in the correct chapter directory. Create a new directory if the topic doesn't fit an existing chapter.
4. Do not modify the format or structure of existing articles unless explicitly asked.
